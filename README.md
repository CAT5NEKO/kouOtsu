# 契約書甲乙変換ツール

契約書に書いてある甲と乙、長時間読み通してるとこんがらがってくるので、自分の名前や相手の会社に置き換えられるツールを作りました。
[こちら](https://kouotsu.netlify.app)で動作確認ができます。

聞くところによると任意の文章を推しカプに置き換える使い方もあるそうで

## 保存形式

返還後のドキュメントはPDF、DOCX、ODTで保存できるようにしています。  
デフォルトはTXTです  

- 既定の保存形式はTXT
- 形式選択プルダウンから DOCX / ODT / PDF を選択して保存可能
- GoogleDocsは直接対応していませんが DOCXで読み込めます
- Office 97 の .doc バイナリ出力は対象外です
